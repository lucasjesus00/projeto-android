# Projeto Android — Curiosidades Tech

Página de conteúdo sobre a história do mascote do Android, com texto, imagens adaptáveis a diferentes larguras de tela, links externos e vídeo incorporado. O projeto é um exercício de desenvolvimento front-end e apresenta o artigo em uma interface responsiva.

## Tecnologias utilizadas

- **HTML5** — estrutura semântica, conteúdo e imagens responsivas.
- **CSS3** — apresentação visual definida em `style/style.css`.
- **Frameworks e bibliotecas:** não utilizados.

## Como executar localmente

Não há dependências para instalar. É necessário apenas um navegador moderno. O vídeo incorporado e os links externos dependem de conexão com a internet.

1. Clone o repositório:

   ```bash
   git clone https://github.com/lucasjesus00/projeto-android.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd projeto-android
   ```

3. Abra `index.html` no navegador. Como alternativa, inicie um servidor local na raiz do projeto:

   ```bash
   python -m http.server 8000
   ```

4. Acesse [http://localhost:8000](http://localhost:8000).
